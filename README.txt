Запуск на новом компьютере:
1. Установите Python 3.13 (python.org) с галочкой "Add Python to PATH".
2. Распакуйте архив и запустите start.bat двойным щелчком.
3. Откроется http://localhost:8000
Вход разработчика: developer / developer123
Чтобы открыть с других устройств в сети: http://IP-этого-компьютера:8000
(разрешите порт 8000 в брандмауэре Windows).
